# DC: portfólio de projetos 3D

Site de portfólio com galerias de projetos de interiores e de fachadas. Desenhei no Figma e implementei em HTML, CSS e JavaScript.

**Demo:** https://SEU-USUARIO.github.io/dc-portfolio/ · **Design:** [link do Figma ou Behance]

Os formulários de Propostas e Contatos abrem o aplicativo de e-mail com a mensagem pronta. Edite os contatos no começo do `app.js`. As imagens são de renders do autor dos projetos.

Para rodar, abra o `index.html` no navegador.
